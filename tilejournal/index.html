常见问题

怎么记一局？

在「牌局」页点右上角的 +，填写类型、地点和每位玩家的输赢。合计不为 0 时，可以点「自动配平」把差额填给最后一位还没填的玩家。

没上桌也能记录吗？

可以。「我的参与」选择未参与，这一局会保留在历史里，但不计入你的收益、胜率和连胜。

怎么备份或换手机？

设置 → 数据与 iCloud → 完整备份，会导出一个 JSON 文件；在新设备上用「从备份合并」导入即可。合并只添加新记录，不会覆盖已有资料。登录同一 iCloud 账户的设备也会自动同步。

怎么删除全部资料？

设置 → 数据与 iCloud → 删除全部资料。删除后在关闭 App 前都可以撤销。

输赢颜色可以改吗？

设置 → 主题与配色，可以选择绿色或红色表示赢，并在五套主题之间切换。

English

TileJournal is a personal journal for mahjong and card-game sessions: results, players, places, photos and statistics. Back up from Settings → Data & iCloud → Full Backup and merge it on another device; devices on the same iCloud account sync automatically. Delete everything from Settings → Data & iCloud → Delete All Data.
